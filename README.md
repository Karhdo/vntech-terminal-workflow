# Terminal-first on a MacBook — vntech talk

Slides for a talk by **Khanh Do** on a terminal-first Mac setup: `.zshrc` and dotfiles, terminal and CLI tools, multiple git accounts, runtime config, AWS SSO, and Claude Code sessions in tmux popups. All config shown comes from [Karhdo/dotfiles](https://github.com/Karhdo/dotfiles).

- [`presentation/`](presentation/) — the deck: plain HTML/CSS/JS, no build step. See its [README](presentation/README.md) to run it locally.
- [`presentation/terminal-workflow-outline.md`](presentation/terminal-workflow-outline.md) — talk outline (Vietnamese), the source for slide content.
- `.github/workflows/deploy-pages.yml` — publishes `presentation/` to GitHub Pages on every push to `main`.

Slide engine and styling come from the vntech load-balancer deck.
