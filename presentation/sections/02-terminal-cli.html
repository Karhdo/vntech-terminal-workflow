WezTerm

66 lines of Lua replace a preferences window

local config = wezterm.config_builder()

config.font = wezterm.font("Hack Nerd Font Mono")
config.font_size = 11
config.color_scheme = "Tokyo Night"
config.enable_tab_bar = false       -- tmux owns tabs
config.window_decorations = "RESIZE"
config.use_ime = true               -- Vietnamese input

-- wallpaper drawn INSIDE the window, dark overlay on top
config.window_background_opacity = 1.0
config.background = {
  { source = { File = wallpaper }, hsb = { brightness = 0.12 } },
  { source = { Color = "#1a1b26" }, opacity = 0.96 },
}

config.keys = {
  { key = "Enter", mods = "SHIFT",
    action = wezterm.action({ SendString = "\x1b\r" }) },
}
  • No tab bar. WezTerm only draws text; tmux handles windows and panes.
  • Wallpaper, not transparency. A transparent window showed whatever app was behind it, and text got hard to read. The image plus a 96% overlay looks the same over any app.
  • Shift Enter sends ESC + CR, which Claude Code reads as "new line" instead of "send".
  • Nerd Font carries the icons that starship, eza and tmux print. Without it you see empty boxes.

# checkout any branch, local or remote, with fzf
gcof() {
  local branch
  branch=$(git branch --all | sed 's/^[* ] //' | fzf) || return
  git checkout "${branch#remotes/origin/}"
}

Dotfiles philosophy

Config is code; credentials are not

  • 1 · in gitEvery config file is committed. You get a diff, a history and a backup for free.
  • 2 · no secrets~/.gitconfig-karhdo, ~/.ssh, .envrc tokens and ~/.aws stay outside the repo. .gitignore blocks .config/gh/ and .config/github-copilot/.
  • 3 · comment why"Testcontainers ignores Docker contexts" beats "set DOCKER_HOST".
  • 4 · one themeTokyo Night in WezTerm, tmux, bat, fzf, delta, lazygit and Claude Code. A screenshot from any tool looks like the same machine.
  • 5 · README = setupIf a step isn't written down, the next laptop won't get it.
