PATH

Each export puts its directory first, so the last one in .zshrc wins

.zshrc, top to bottom
eval "$(brew shellenv)"              # /opt/homebrew/bin
export PATH="$HOME/.cargo/bin:$PATH"
export PATH="$HOME/.local/bin:$PATH"
export PATH="/usr/local/bin:$PATH"
eval "$(fnm env --use-on-cd …)"     # fnm's node
export PATH=$JAVA_HOME/bin:$PATH
export PATH="…/libpq/bin:$PATH"      # last line
echo $PATH | tr : '\n' (lookup order)
/opt/homebrew/opt/libpq/bin      # 1st: last export
…/temurin-21/Contents/Home/bin
…/fnm_multishells/83139_…/bin
/usr/local/bin
…
/Users/khanhdo/.local/bin
/Users/khanhdo/.cargo/bin
/opt/homebrew/bin                 # first export, now last
  • Two directories with the same binary? The one higher in the list runs. which -a node shows every match, in order.
  • To win over Homebrew, a directory has to be exported after brew shellenv.
  • Every tmux pane runs .zshrc again and prepends everything twice. typeset -U path at the top keeps entries unique.

Docker without Docker Desktop

The Docker CLI is free; the engine can run in a small VM called Colima

# first run
colima start --cpu 4 --memory 8 \
  --vm-type vz --vz-rosetta
# later
colima start
colima stop     # gives the RAM back
colima status

# ~/.docker/config.json
"credsStore": "osxkeychain"
  • Same docker and docker compose commands as before. Only the engine moved.
  • Testcontainers ignores Docker contexts: set DOCKER_HOST to Colima's socket (and TESTCONTAINERS_DOCKER_SOCKET_OVERRIDE=/var/run/docker.sock).
  • Bind mounts work only from $HOME: Colima doesn't share /tmp, so it mounts as an empty folder.
